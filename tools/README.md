# tools/

Drop **PresentMon.exe** here (or beside `FrameProbe.exe`) to enable frame-time
capture.

PresentMon is Microsoft's open-source frame-capture utility:
https://github.com/GameTechDev/PresentMon

FrameProbe also looks here for `nvidia-smi.exe`, though on NVIDIA systems it is
normally already on `PATH` (installed under `System32`).

These binaries are **not** bundled in the repository — download the versions
appropriate for your machine.
